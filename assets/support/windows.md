> ⚠️ **Do not** run the installer as Administrator

Download the installer for your PC. Run it and a graphical interface should open

- GUI: [x64](https://github.com/Equicord/Equilotl/releases/latest/download/Equilotl.exe), [ARM64](https://github.com/Equicord/Equilotl/releases/latest/download/Equilotl-arm64.exe)

If the graphical installer fails to open, download the CLI build instead. Run the file and follow the instructions provided in the terminal window to install Equicord.

- CLI: [x64](https://github.com/Equicord/Equilotl/releases/latest/download/EquilotlCli.exe), [ARM64](https://github.com/Equicord/Equilotl/releases/latest/download/EquilotlCli-arm64.exe)
