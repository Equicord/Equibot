Run the following command in your terminal and follow along with the instructions/prompts

```sh
sh -c "$(curl -sS https://raw.githubusercontent.com/Equicord/Equilotl/main/install.sh)"
```

Alternatively, download the installer for your setup:

- GUI, X11: [x64](https://github.com/Equicord/Equilotl/releases/latest/download/Equilotl-x11), [ARM64](https://github.com/Equicord/Equilotl/releases/latest/download/Equilotl-x11-arm64)
- GUI, Wayland: [x64](https://github.com/Equicord/Equilotl/releases/latest/download/Equilotl-wayland), [ARM64](https://github.com/Equicord/Equilotl/releases/latest/download/Equilotl-wayland-arm64)
- GUI, combined: [x64](https://github.com/Equicord/Equilotl/releases/latest/download/Equilotl), [ARM64](https://github.com/Equicord/Equilotl/releases/latest/download/Equilotl-arm64)
- CLI: [x64](https://github.com/Equicord/Equilotl/releases/latest/download/EquilotlCli-linux), [ARM64](https://github.com/Equicord/Equilotl/releases/latest/download/EquilotlCli-linux-arm64)
